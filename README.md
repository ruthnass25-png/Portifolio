# Ruth Nassiwa Portfolio — HTML, CSS & JavaScript

A responsive, futuristic portfolio built with plain HTML, CSS and JavaScript. No React, Vite, npm or build step is required.

## Run it
1. Extract the ZIP.
2. Open `index.html` in your browser.

Optional local server (from this folder): `python -m http.server 8000`, then visit `http://localhost:8000`.

## Publish it
Upload the project folder to Netlify Drop, or push it to GitHub and import it into Netlify or Vercel. There is no build command; publish the project root.

## Personalise before publishing
- Replace the portrait placeholder with your photo.
- Replace `YOUR-EMAIL@example.com` in `index.html` with your real email.
- Add real projects and verified experience when you are ready. No projects, employers or certificates have been invented.

The 3D-inspired hero sphere is made with CSS. Google Fonts and Lucide icons load from CDNs, so an internet connection is needed for those extras.
